# GPMx Signature Audio Branding Required Before Release

## Locked rule

All release-bound KUT audio must include:

1. Required padding
2. Slight fade at KUT end
3. Twinkle / GPMx Signature Audio Branding

These are required components.

They are not optional.

They are not added only upon demand.

They must be ingrained into processing intake.

## SSOT

The single source of truth is:

`data/audio-branding/gpmx-signature-audio-branding-ssot.json`

No product, theme, holiday, HUG, TUG, BUG, KUPID, or local page may create a separate signature-audio rule.

## KKr to HOME rule

When an item is registered from KKr into HOME / canonical inventory, GPMx Signature Audio Branding must be applied as part of processing intake.

The item cannot be marked release-ready until required padding, slight end fade, and Twinkle are present or a BTI-approved equivalent is recorded.

## STI / STI-Slot / BTI / BF rule

Padding is an STI.

End fade is an STI.

Twinkle is an STI.

The required signature package requires STI-Slot handling, BTI definition, BF guardrail, and Release Gate / Outlet approval.

## Product rule

K-KUT, Short-KUT, HUG, TUG, and BUG all inherit this rule.

BUGs remain Short-KUT-only, $1.99, repeatable 1–5, and schedule-required when repeated.

Signature Audio Branding does not turn a BUG into a separate audio identity.

The canonical audio identity remains neutral KUT / KK / II inventory.

## Fail-closed rule

If required padding, slight fade, or Twinkle is missing, the item may be reviewed or processed but must not enter public release, public outlet, delivery outlet, or BUG-eligible release index.
