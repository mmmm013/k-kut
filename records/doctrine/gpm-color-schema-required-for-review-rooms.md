# GPM Color Schema Required for Review Rooms

All GPMx / K-KUT / KKr / KUT processing rooms must use the GPM color schema.

A playable review room is not neutral generic UI.

It is part of the GPMx controlled processing environment.

## Required

- GPM Color Schema SSOT
- GPM visual tokens applied to the HTML room
- Visible statement that the room is inside GPMx processing control
- Twinkle / GPMx Signature Audio Branding requirement visible before any render or Release Gate

## Forbidden

- Generic dark room with no GPM color schema
- Review room with no Twinkle / Sonic Branding gate
- Room that implies a candidate is release-ready before signature processing
