# K-KUT Theme Container / Audio Identity Separation Lock

## Absolute rule

A KK is a KK.
A KUT is a KUT.
An II is an II.
A theme is a theme.

Themes are user-determined containers for audio selection.

Themes may accept, filter, summon, compare, and provide eligible KUTs.

Themes must never own, title, identify, rename, or canonically path audio.

## Audio identity rule

Audio identity must be neutral.

Allowed neutral identities include:

- II-*
- KK-*
- KUT-*
- KKA-*
- SEL-* only for a temporary selection/session/container slot

Forbidden audio identity examples:

- Father’s Day KK1
- FD2026-KK1
- Wedding KK2
- Christmas KUT
- fathers-day-* as a canonical audio id
- holiday-* as a canonical audio id

## Public display rule

Public shoppers may see only simple comparison slots:

- KK1
- KK2
- KK3

Those are display slots only.

The current container route may display theme context as navigation, such as `/fathers-day`, but the displayed KK number does not belong to that theme.

## Navigation/context rule

Theme context belongs only to navigation, routing, and session/container context.

Allowed:

- route: `/fathers-day`
- page context: “Father’s Day”
- container purpose: visitor is shopping for a Father’s Day HUG

Forbidden:

- audio id: `FD2026-KK1`
- audio title: `Father’s Day KK1`
- canonical audio path: `/father-days-kks/...`
- internal audio identity based on a holiday, theme, occasion, or campaign

## Internal detail rule

Internal/admin records must preserve full detail:

- neutral II id
- neutral KK id
- neutral KUT id
- canonical neutral audio URL
- legacy/noncanonical paths when needed
- source PIX / LT-PIX lineage
- artist/source/session where known
- BLK / CI / II detail where known
- feeling/musical/emotional selection metadata
- release status
- pricing tier
- checkout mapping

The detail is internal. The identity is neutral.

## Container mapping rule

A theme/container/session may map visible slots to neutral audio inventory:

- `SEL-* / KK1 -> KUT-*`
- `SEL-* / KK2 -> KUT-*`

But the theme/container/session does not own the audio.
