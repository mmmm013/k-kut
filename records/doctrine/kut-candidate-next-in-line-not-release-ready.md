# KUT Candidate Language: Next-in-Line, Not Release-Ready

## Locked wording

Use:

`Next-in-line KUT Candidate`

## Meaning

A Next-in-line KUT Candidate is not released.

It is not public-ready.

It is not final.

It is not automatically product-ready.

It is the next candidate to enter controlled processing.

## Required processing before release

Every Next-in-line KUT Candidate must still pass:

1. Exact cut / recut
2. Required padding
3. Slight end fade
4. Twinkle / GPMx Signature Audio Branding
5. BTI restrictions
6. BF guardrails
7. Neutral KUT canonicalization
8. Final human Release Gate / Outlet decision

## Why this matters

The old label can sound final.

“Next-in-line KUT Candidate” keeps the process accurate: a human heard enough value to move it forward, but the item is still inside processing control.
