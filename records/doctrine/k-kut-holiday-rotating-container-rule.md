# K-KUT Holiday Rotating Container Rule

## Locked behavior

Holidays rotate alone.

A holiday page is a temporary use-case container. It does not own any II, CI, K-KUT, K-KUT KOMBO, Sound, TRM, phrase, expression, or HUG product.

Holiday containers are empty until called.

When a holiday is active, the holiday container may summon eligible K-KUT system items for that temporary use case.

When the holiday call ends, all summoned items return home to their proper K-KUT system location until the next call.

## Internal path

1. K-KUT system home
2. Holiday call
3. Temporary holiday container
4. User / MC-BOT narrowing
5. Decision-stage product card
6. Checkout / send
7. Return home after holiday use

## Public-language rule

Public holiday pages must not expose internal doctrine, routing, or engineering language.

Do not show these terms to shoppers:

- premade
- resident
- inventory
- Release Gate
- Dispatch
- DP
- product-bound
- art-tail
- canonical
- Twinkle
- ownership by holiday
- source lane
- review lane
- proof lane

Public holiday pages should say:

- available K-KUT options
- ready matches
- Father’s Day HUG
- tell MC-BOT the feeling
- hear a match
- adjust it
- send it
- private HUG link

## Public shopper posture

The shopper tells us what to do.

MC-BOT does not tell the shopper what to do. MC-BOT narrows, supports, offers matches, and helps the shopper approve, adjust, browse, or send.

Pricing stays near the decision point, not at the top of the holiday page.
