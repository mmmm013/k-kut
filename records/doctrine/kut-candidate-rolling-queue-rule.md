# KUT Candidate Rolling Queue Rule

## Core rule

There is no fixed “approved” pile.

There is only a rolling KUT candidate lane.

## Correct lane sequence

Next-in-line KUT Candidate
→ In processing
→ Processed candidate review
→ Release Gate
→ Outlet / Release

Or, when not ready:

Next-in-line KUT Candidate
→ In processing
→ Processed candidate review
→ Recut / Hold

## Candidate replacement rule

When a Next-in-line KUT Candidate moves into processing, that candidate leaves the next-in-line slot.

The next best eligible candidate may then move into the next-in-line position.

This keeps candidate review active, current, and replenishing.

## What Next-in-line means

Next-in-line does not mean released.

Next-in-line does not mean public-ready.

Next-in-line does not mean product-ready.

Next-in-line means the candidate earned controlled processing attention.

## Required processing before Release Gate

Every candidate must still receive:

1. Exact cut / recut
2. Required padding
3. Slight end fade
4. Twinkle / GPMx Signature Audio Branding
5. BTI restrictions
6. BF guardrails
7. Neutral KUT canonicalization
8. Final human Release Gate / Outlet decision
