# GPMx DP Law

## Definition

DP means Delivered Present / Delivery Page.

A DP is recipient-facing.

For Mother’s Day, the DP is what the mother sees when she receives the K-KUT HUG.

## Correct Flow

Buyer page:

- choose
- preview
- buy
- send

DP:

- recipient opens
- sees the gift
- plays the audio
- feels the HUG
- replays / saves / replies / shares

## What a DP Is Not

A DP is not the buyer catalog.

A DP is not the 38-option browsing page.

A DP is not the internal emotional routing layer.

A DP is not a technical playlist.

## What a Mother’s Day DP Must Feel Like

A Mother’s Day DP must feel like a received gift.

It should say, plainly:

- You received a Mother’s Day K-KUT HUG.
- To: Mom
- From: Sender
- Personal message
- Play Your HUG

The audio should be the purchased Short KUT, HUG, or Big HUG.

## Recipient Actions

A DP may offer:

- replay
- save
- share
- send a thank-you back
- create one for someone else

## Buyer Actions Stay Elsewhere

Buying, browsing, pricing, and catalog selection belong on the buyer page.

The DP is for receiving.

## Public Naming

Use:

- Short KUT
- HUG
- Big HUG

Do not use mK or mini-KUT in recipient flow.

## GPMx Audio Law Applies

DP audio must follow GPMx Audio Law:

- small end fade when needed
- end padding only when needed
- no automatic start padding
- natural song endings stay natural
