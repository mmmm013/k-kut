# K-KUT Options Rules

## Core Rule

When a user chooses a song, the next screen must show K-KUT options.

Never show only one option.

Every selected song must show at least 10 K-KUT options.

## Sensible Path

Purpose  
→ Song  
→ At least 10 K-KUT options  
→ Play option  
→ Choose this HUG  
→ Confirm  
→ Checkout

## No Dead Ends

Do not tell users a category is coming soon when KKs exist.

Do not tell users a song is coming soon when KKs exist.

Do not collapse the user into Mother’s Day unless they choose the demo/help path.

## Missing Audio Rule

If a specific preview file is not wired yet, the option still appears.

The option may show a clear preview-status line, but the product path must remain intact.

## User POV

A user who asks to hear a KUT expects choices.

They should feel:

I picked a purpose.  
I picked a song.  
Now I can compare several K-KUT moments.  
I can play them.  
I can choose the one that feels right.
