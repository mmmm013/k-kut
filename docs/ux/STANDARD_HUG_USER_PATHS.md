# Standard HUG User Paths

## Primary Guided Path

Welcome  
→ broad purpose  
→ narrower emotional lane  
→ finer fitting song set  
→ K-KUT moment options  
→ user chooses one  
→ confirmation  
→ checkout  
→ playable HUG delivery

## Guided Principle

General → narrower → narrower → fitting options → user satisfied → checkout.

## Standard Screens

### 1. Welcome

Purpose:
Explain HUG simply.

User action:
I understand — start.

Alternate:
I don’t understand — show me the demo.

### 2. Broad Purpose

Purpose:
Start broad.

Examples:
Love, Gratitude, Hard Feelings, Celebration, Comfort.

User action:
Choose one.

### 3. Emotional Lane

Purpose:
Narrow the broad purpose into a more precise human feeling.

Example under Hard Feelings:
Sorry, Reflection, Hurt, Cry, Sorrow / Break Up.

User action:
Choose the lane that fits.

### 4. Fitting Song Set

Purpose:
Show only songs that fit the selected lane.

Rule:
Quantity never beats fit.

If more fitting songs exist:
Show me another set.

If fewer fitting songs are available:
More fitting songs are being reviewed. We only show songs that fit this choice.

User action:
Choose a song or ask for another set.

### 5. K-KUT Moment Options

Purpose:
Let user hear / compare K-KUT moments from the chosen song.

Rules:
- Show option cards.
- Do not show dead Play buttons.
- Show Play only when preview audio exists.
- If preview audio is not loaded, say Preview loading.
- User can still choose an option if allowed.

User action:
Play, compare, choose this one.

### 6. Confirm

Purpose:
Let user verify the selected HUG.

Show:
Purpose, lane, song, K-KUT moment.

User action:
Continue to checkout or go back.

### 7. Checkout

Purpose:
Final purchase.

Copy:
This order includes one selected HUG.

Do not show:
18A, ASCAP, internal codes, or licensing explanations in the selection flow.

## Alternate Paths

### Confused User

I don’t understand  
→ demo  
→ play demo  
→ choose HUG  
→ checkout

### Another Set

Song set  
→ Show me another set  
→ next fitting batch  
→ choose or repeat

### Go Back

Checkout  
→ Confirm  
→ K-KUT options  
→ Song set  
→ Emotional lane  
→ Broad purpose

### Ask a Question

User asks guide for help at any step.

Guide should answer in the context of the current step only.

### Start Over

User may restart when available.

Restart should clear current selection and return to broad purpose.

## Audio Rule

Any new Play click:

1. Stops every other audio.
2. Resets every other audio to 0.
3. Starts selected audio from 0.

No overlapping audio.

## Mobile Rule

All audio must be user-tap initiated.

Do not rely on autoplay.

## Satisfaction Rule

Do not push checkout until user has confirmed:

This is the one.
