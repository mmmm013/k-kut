# K-KUT HUG Guided Choice Process

## Core Rule

K-KUT HUG selection must move from broad to narrow until the user is satisfied.

General  
→ narrower  
→ narrower  
→ fitting options  
→ user satisfied  
→ checkout

## Standard User Path

Purpose  
→ emotional lane  
→ fitting song set  
→ K-KUT moment options  
→ choose one  
→ confirm  
→ checkout

## User Freedom

At every step, the user must be able to:

- Go back
- Ask for help
- Ask for a demo
- Ask for another set
- Start over when available

## Satisfaction Rule

Do not move the user to checkout until the user has confirmed:

This is the one.

## Fit Rule

Quantity never beats fit.

A song, K-KUT option, or lane must not appear just to fill space.

If fewer fitting choices are available, say so plainly.

Do not use filler.

## Song Set Rule

Song choices must fit the selected emotional lane.

Show fitting songs in small batches.

If more fitting songs exist, offer:

Show me another set.

If fewer fitting songs exist, say:

More fitting songs are being reviewed. We only show songs that fit this choice.

## K-KUT Option Rule

When a user chooses a song, show K-KUT moment options for that song.

Do not show a Play button unless a real preview audio file exists.

If preview audio is not loaded, say:

Preview loading

The user may still choose the K-KUT moment.

## Audio Rule

Only one audio may play at a time.

Any new Play click must:

1. Stop all other audio.
2. Reset all other audio to 0.
3. Start the selected audio from 0.

## Forbidden UX

Do not show:

- Internal labels
- 18A
- ASCAP explanations in the choice flow
- Fake coming soon dead ends
- One lonely option when more fitting choices exist
- Unrelated songs
- Dashboard clutter
- Progress panels
- Current-action panels
- Decorative BOT badges

## Guide Language

Use simple guide lines:

Let’s start broad.

Now let’s narrow it.

Choose the kind that fits best.

Here are fitting songs for that feeling.

Want a different set? Ask for another set.

Now listen to K-KUT moments from that song.

Choose the one that feels right.

Review your HUG.

If this is the one, continue to checkout.

## User POV Test

Every screen must answer:

1. What am I choosing now?
2. Why does this choice matter?
3. What do I click next?
4. Can I go back or ask for another set?
5. Am I being shown only fitting choices?
