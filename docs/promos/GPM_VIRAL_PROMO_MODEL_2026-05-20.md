# GPM Viral Promo Model — K-KUT / HUGs

## Status

Working public-growth plan. Use for testing, copy, landing pages, social posts, and fast promo loops.

## Core Thesis

Viral promos are the attention engine.

They should make people understand K-KUT HUGs in seconds:

> Send a feeling, not just a message.
>
> A private song moment for when words are not enough.

The viral layer should not explain PIX, CC, KUT materialization, GPMx architecture, or backend doctrine. The public only needs to hear real audio, understand the occasion, and feel the reason to send.

## Viral Goal

Drive cheap discovery and fast behavior testing.

Primary goals:

1. Get visitors to hear real audio within 10 seconds.
2. Make sharing feel natural.
3. Learn which emotional lanes create plays, clicks, and purchases.
4. Feed winning lanes into mid-range paid packages.
5. Build proof that K-KUT HUGs map to real greeting-card and personal-gift behavior.

## Public Positioning

Preferred headline language:

- Send a feeling, not just a message.
- A private song moment for someone who matters.
- When words are not enough, send a HUG they can hear.
- For when you cannot be there — and sometimes even when you can.
- Hear it. Choose it. Send it privately.

## Viral Offer Shape

Each viral promo should have:

1. Occasion hook.
2. One visible audio player.
3. One emotional promise.
4. One CTA.
5. Shareable link.
6. Checkout path or email capture.

Minimum page structure:

1. Headline.
2. Real audio above fold.
3. Short explanation.
4. CTA: `Use this HUG`.
5. Trust line: `Private playable link. Real audio. Easy to send.`

## Viral Loop Ideas

### Loop A — Hear, choose, send

1. User lands on promo page.
2. Audio plays.
3. User clicks `Use this HUG`.
4. User sends private link.
5. Recipient hears and sees `Send one back`.

### Loop B — MC-BOT chooser

1. User clicks `Find the right HUG`.
2. MC-BOT asks occasion and feeling.
3. MC-BOT recommends one HUG.
4. User hears and sends.

### Loop C — Social prompt

Examples:

- “Who needs to hear this today?”
- “Send this to someone with a birthday this week.”
- “A song moment for when sorry matters.”
- “Not a card. Not a text. A private music HUG.”

## Viral Metrics

Track:

1. Page visits.
2. Audio plays.
3. Audio completion or repeat plays.
4. CTA clicks.
5. Checkout starts.
6. Purchases.
7. Shares.
8. Recipient opens.
9. Send-one-back clicks.
10. Return visitors.

Most important early metric:

> Visitor hears real audio within 10 seconds.
