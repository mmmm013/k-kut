# System Path Naming and Public Audio Rule

## Locked Rule

Do not use customer-facing names, holidays, people names, song titles, PIX titles, artist names, or promo titles as system component names.

Do not put review/proof audio in public paths.

## Path Roles

public/ is only for customer-safe assets.

ops/review/ is for internal review/proof.

public/ii-delivery/ is for finished II / DP delivery audio only.

## Audio Rule

Raw KK proof is not customer audio.

Review audio is not customer audio.

Customer delivery audio must be finished II / DP audio with padding and Twinkle baked in.

AUDIO CAN NEVER LEAVE AN II.
