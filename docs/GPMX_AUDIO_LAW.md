# GPMx Audio Law

## End Fade / Ending Rule

All KUT / K-KUT cuts must be checked for ending quality.

### Law

Add a small end fade when needed to avoid abrupt cutoffs.

### Exception

Do not fade natural song endings that already resolve cleanly.

### Padding

Do not add start padding automatically.

Use start padding only if the cut starts too abruptly.

### End Treatment

Use end padding and/or end fade only when needed.

Natural ending beats stay natural.

## Current Application

Mother’s Day K-KUT / HUG program follows this law:

- Short KUTs must not end with ugly hard cuts.
- HUGs must feel complete.
- Big HUGs should preserve natural musical endings when they resolve cleanly.
- No mKs / mini-KUTs in buyer flow.
