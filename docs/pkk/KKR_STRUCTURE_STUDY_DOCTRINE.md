# PKK-KKR-001 — KKr Structure Study Doctrine

## VOC Lock

KKr must learn songwriting and song structure before fine slicing.

Public K-KUT buyer flow is KK-only for now.

No mKs.
No mini-KUTs.
No public fine-slice exposure.

## Core Objects

PIX = full song / source work.

KK = controlled song-section audio object.

CC = Celebration Card / customer-facing meaning supported by a KK.

mK = fine-slice emotional object. mKs may work internally, but they are banned from public buyer flow unless explicitly re-approved.

Novelty Silo = separate capture area for special moments, inflections, surprise, discord, delivery, and emotional turns.

## Songwriting Study Requirements

KKr studies:
- music composition
- songwriting with lyrics
- songwriting without lyrics
- popular song structure from 1930 to current
- lyricist behavior
- instrumental transition cues
- intro behavior
- first vocal note
- verse function
- pre-chorus lift
- chorus arrival
- bridge departure
- return-to-chorus cues
- outro resolution
- vocal inflection
- vocal delivery
- stress
- emphasis
- discord / release
- novelty moments

## Thank You Rule

For Thank You and similar songs:

Intro = start of track through just before first vocal note.

First vocal note = beginning of V1.

KK boundaries must be based on musical structure, not arbitrary chunks.

## Required Study Passes

### Pass 1 — Composition Map

Find:
- intro
- verse
- pre-chorus
- chorus
- bridge
- outro
- instrumental transitions

Output:
major section map

### Pass 2 — Lyric / Vocal Delivery Map

Find:
- first vocal note
- phrase starts
- line endings
- breath points
- emphasis
- melodic lift
- vocal intensity changes
- repeated chorus differences

Output:
lyric-aligned section map

### Pass 3 — Novelty / Cue / Alternate-Look Map

Find:
- instrumental cue
- texture change
- discord
- surprise
- emotional turn
- signature phrase
- section transition
- possible future fine-slice moments

Output:
Novelty Silo candidates

### Pass 4 — KK Candidate Review

Generate local-only KK candidate files after boundaries are estimated.

Output:
review-only KK candidates

### Pass 5 — KK Approval

Approve only if:
- section boundary is musically valid
- lyric structure matches
- audio file is playable
- file is KK-only
- title matches inventory
- no banned public object is included

## Control Rule

Do not publish, sell, or label a KK publicly until structure, boundary, audio, and title proof pass.
