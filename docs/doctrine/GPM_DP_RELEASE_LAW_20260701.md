# GPM DP Release Law — 2026-07-01

## Locked release law

ALL released IIs require approved GPM DP.

ALL GPM DP requires:

1. Front padding to cushion abrupt starts.
2. Content-end cushion / small post-content padding.
3. STI GPM Twinkle.

NO Twinkle = NO Release.

NO approved DP = NO recipient delivery.

## Inventory approval is not release approval

Approval for inventory means the II may be stocked, controlled, reviewed, and prepared.

Approval for inventory does not mean the II is recipient-ready.

An inventory-approved II must remain blocked from buyer/recipient delivery until GPM DP is completed, proofed, and approved.

## Recipient expectation

Recipients should hear the STI GPM Twinkle on released IIs.

If the released item does not include approved front padding, content-end cushion, and STI GPM Twinkle, it has failed Release Gate and must not be delivered.

## Operating rule

Inventory-approved IIs are not recipient-ready until GPM DP is completed, proofed, and approved.

GPM DP must include front padding, content-end cushion, and STI GPM Twinkle.

No Twinkle means no Release.

No approved DP means no recipient delivery.
