# K-KUT User Touchpoint Inventory

## Homepage

User can:
- Play / replay Founder Welcome
- Start guided path
- Buy live Mother’s Day HUG now
- Ask for demo

Expected:
- Welcome is optional after first listen.
- Guided path starts cleanly.
- Buy path goes to live Mother’s Day page.
- Demo path goes to Mother’s Day page.

## Guided Path

Expected path:

Welcome  
→ Purpose  
→ Smaller emotional lane  
→ Fitting song set  
→ K-KUT options  
→ Confirm  
→ Checkout

## Required User Actions

Purpose:
- choose Love / Gratitude / Hard Feelings / Celebration / Comfort

Smaller lane:
- choose refined emotional type

Song:
- choose fitting song
- ask for another set when available
- go back

K-KUT options:
- Play when preview exists
- see Preview loading when preview is not wired
- choose this one
- go back

Confirm:
- review selected purpose, lane, song, K-KUT moment
- continue to checkout
- hear options again

Checkout:
- continue to Stripe
- go back

## Live Buyer Path

Homepage  
→ Buy live Mother’s Day HUG now  
→ Mother’s Day HUG page  
→ Play demo  
→ Choose this HUG  
→ Checkout  
→ Stripe

## Audio Requirements

- Any new Play click stops every other audio.
- Other audio resets to 0.
- Selected audio starts from 0.
- No overlapping audio.
- Refresh must not resume audio.
- Leaving page must not continue audio.

## Link Requirements

- /
- /hug/mothers-day
- /privacy
- /terms
- G Putnam Music external link
- Stripe checkout
- demo audio files

## Forbidden

- 18A
- ASCAP in user choice flow
- internal labels
- fake coming soon
- dead Play buttons
- wrong-fit songs
- unclear checkout
