# UI Design Lock — K-KUT Mother’s Day HUG

## Locked Design Rule

The current Mother’s Day HUG UI design is approved and locked.

Do not change the visible UI, layout, colors, flow, copy structure, card structure, button structure, or page behavior without explicit owner consent from Gregory D. Putnam.

## Current Approved Direction

The design looks awesome and should remain stable.

The system may continue to improve metadata, audits, internal controls, product rules, and 4PE process logic, but those changes must not alter the visible user interface unless owner-approved.

## Mother’s Day Active Offer Rule

Mother’s Day public offer is KK-only.

LineFeels / CC assets are paused for refinement and must not be offered publicly until owner review is complete.

## Bot Rule

MC-BOT leads the Mother’s Day HUG experience.

GP-BOT is reserved only for intentional Founder / Founder Quote clicks or links.

## Product Control Rule

No downloads.

No SMS sending until approved.

Private HUG link delivery only.

## Change-Control Requirement

Any proposed UI change must be documented first and approved by the owner before implementation.

Accepted internal work without owner approval:

- metadata refinement
- audit scripts
- product-control rules
- backend capture
- private-link controls
- non-visual safety checks

Blocked without owner approval:

- visual layout changes
- new public sections
- new cards
- copy rewrites
- button behavior changes
- checkout flow changes
- audio display changes
- automatic BOT voice changes
