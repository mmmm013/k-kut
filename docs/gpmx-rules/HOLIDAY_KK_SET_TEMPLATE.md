# Holiday KK Set Template

## Purpose

A Holiday KK Set is a guided emotional HUG flow for a specific holiday. Mother’s Day is the first template.

The product is not a raw audio file. The product is a private HUG link that opens a controlled K-KUT page.

## Core Rule

Users see one focused section or set at a time. The system may have many available KKs, but MC-BOT leads the user step-by-step.

## Divisions

K-KUT has these major divisions:

1. Holiday HUGs
2. Personal HUGs
3. Brand / Business HUGs
4. Song / Invention Products

## Holiday vs Personal

Holiday HUGs are tied to a calendar occasion and recipient role.

Examples:
- Mother’s Day
- Father’s Day
- Birthday
- Anniversary
- Christmas
- Valentine’s

Personal HUGs are tied to a human sentiment and can be sent any time.

Examples:
- Thank You
- I’m Sorry
- I Miss You
- I Love You
- Thinking of You
- Encouragement

## Mother’s Day Template

Mother’s Day is the first Holiday KK Set template.

Flow:

1. MC-BOT greets first.
2. User chooses or types the feeling.
3. System selects fitting KKs using KKr metadata.
4. User sees one focused set at a time.
5. User previews options in that set.
6. User can ask for:
   - softer
   - stronger
   - more peaceful
   - more grateful
   - another set
7. User chooses one HUG.
8. User checks out.
9. Buyer receives a private HUG link.
10. Buyer sends the link by email, DM, social, or text from their own phone.

## KKr Metadata

Every available KK should include:

- id
- holiday_set
- occasion_type
- personal_type
- recipient
- format_type
- emotional_lane
- intensity
- duration_class
- song_section
- user_display_title
- user_display_description
- audio_url
- internal_source
- download_allowed
- share_mode

## Product Control

HUGs, KKs, FeelLines, previews, guide voice clips, and temporary flow audio are not downloadable products.

The user may share the private HUG page link.

Full song downloads are allowed only when GPM intentionally sells a full song download product.

## Voice Rules

MC-BOT leads Holiday and Personal HUG flows.

GP-BOT is reserved only for intentional Founder / Founder Quote clicks or links.

## Display Rule

Do not display all available KKs at once.

Display one section or one curated set at a time.

## Mother’s Day Available Asset Families

The Mother’s Day / Thank You inventory includes:

- FeelLines / CC short emotional moments
- larger KKs
- song sections

These assets are internal inventory until selected into a guided set.
