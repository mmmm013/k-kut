# GPM Domain Rotation TP Autorun Lock V001

Status: GD-directed and locked on 2026-07-17.

## Canonical tool

GPM LT-PIX TP Review.

## Rule

Every candidate considered for the K-KUT / Sent-i-Meant domain rotation must automatically enter the existing TP validation and review-set process after controlled source proof. A candidate must not remain merely labeled `TP_REQUIRED` or be deferred without creating its TP set.

Required order:

1. Confirm controlled WAV/lossless source and identity binding.
2. Run automatic source/hash/duration/channel/silence and TP-sequence validations.
3. Generate or refresh the ordered GPM LT-PIX TP Review set.
4. Open the source-first review, not a derivative KK/section file.
5. Record human TP marks, N/A decisions, reviewer, and completion status.
6. Run TP consistency validation and endpoint/natural-resolve checks.
7. Feed the completed TP record into KKr blank-slate KK/sK derivation.
8. Record what passed, failed, or changed as learning evidence.
9. Auto-advance to the next candidate only; never auto-approve final inventory.

## Pilot control

`data/site-governance/gpm-domain-feeling-rotation-tpr-set-v001.csv` is the current ordered set manifest. The Foundation is first for immediate review after the candidate list is completed.

## Final inventory controls remain separate

TP completion does not prove final II readiness. Final II still requires approved audible boundaries, natural resolve, canonical GPMx Twinkle at end, registry proof, buyer-safe copy, correct route, live click-to-play proof, and Production BIC PASS.

## Forbidden

- Approval from title or theme alone.
- Skipping TP because a WAV or parent map exists.
- Using an INSTRO as a lyric KK source.
- Treating an automatically proposed TP as human approval.
- Replacing the existing GPM LT-PIX TP Review with a new workflow.
- Production deployment from this documentation lock.
