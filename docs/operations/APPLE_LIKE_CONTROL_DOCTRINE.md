# Apple-Like Control Doctrine

## Status

Active operating doctrine for K-KUT, HUG, KKr, and 4PE.

## Core Principle

For now, G Putnam Music controls the full experience.

We control:

- Product path
- User guidance
- Catalog exposure
- Metadata refinement
- Audio availability
- Checkout
- Delivery
- Public copy
- Compliance
- QA
- Pause / hold decisions
- Launch timing

## Why

K-KUT / HUG / KKr / 4PE are inventions. New inventions require more guidance, not less.

Users should not be dropped into a process. Users should feel led.

The system must feel simple, intentional, human, and reliable.

## User Experience Rule

The user should never face a process-flow issue.

Every user should know:

1. What they are choosing now.
2. Why that choice matters.
3. What to click next.
4. How to go back.
5. How to ask for help.
6. How to ask for another set.
7. How to reach checkout only after satisfaction.

## Founder Control Rule

Until the system is fully mature, do not open it into an uncontrolled marketplace.

Keep it curated.

Keep it guided.

Keep it reviewable.

Keep it owned.

## Forbidden

Do not expose users to:

- Internal codes
- Developer labels
- Raw process language
- Unclear checkout rules
- Fake coming soon dead ends
- Dead Play buttons
- Wrong song matches
- Uncontrolled user paths
- Unapproved charity / sponsor activity
