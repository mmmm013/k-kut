# Father’s Day 8-Box Pagination SLDS

Status: LOCKED

## Decision

Father’s Day public K-KUT display must show 8 boxes at a time.

Use pagination controls:
- Next
- Back

Do not show all options in one long wall.

## Reason

Father’s Day often has 16 KK options and may have 2x more.

The public page must support:
- Page 1: options 1–8
- Page 2: options 9–16
- Page 3: options 17–24

## Doctrine

Use approved playable KKs only.

Do not invent filler boxes.

If fewer than 16 approved KKs exist, display the available approved KKs across pages of 8.

If more approved KKs are added later, pagination handles them automatically.

No public review/admin/internal/proof/staging language.
