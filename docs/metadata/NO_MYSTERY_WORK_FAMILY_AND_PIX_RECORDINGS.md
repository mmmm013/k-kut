# No Mystery Work Family and PIX Recordings

Status: CURRENT DOCTRINE

## Core distinction

"I'm No Mystery" and "No Mystery" may be aliases within one No Mystery work family.

They are not automatically the same PIX recording.

When audio/performance differs, each recording/master is its own PIX.

## KK rule

Each recording can have its own KKs.

A KK must attach to the exact PIX recording from which its audio excerpt was copied.

Do not attach a KK only to the broad work family.

## Backend required lineage

Every No Mystery KK must preserve:

- work family id
- exact parent PIX id
- exact PIX title/internal recording variant
- producer/vocalist when known
- KK id
- KK number
- exact audio path
- section or combo
- start boundary
- end boundary
- approval status
- theme/silo mappings
