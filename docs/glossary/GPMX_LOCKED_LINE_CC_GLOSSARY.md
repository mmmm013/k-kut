# GPMx Locked Line-CC Glossary

Status: LOCKED

## LineDuos — LNDUOs

A LineDuo is a two-line lyric/text CC candidate.

Locked acronym: LNDUO

## LineTrios — LNTRIOs

A LineTrio is a three-line lyric/text CC candidate.

Locked acronym: LNTRIO

## PairedLine — PIMEs

A PairedLine is a contiguous paired-line CC candidate.

Locked acronym: PIME

Use PIME when the pair is specifically contiguous and line-adjacent.

## RhymeSets — RMSTs

A RhymeSet is a rhyme-based CC candidate set.

Locked acronym: RMST

An RMST may contain more than one rhyme pair. It is not limited to one adjacent rhyme pair.

## Locked CC Rules

All LNDUOs, LNTRIOs, PIMEs, and RMSTs require:

- SSOT full-audio URL
- exact excerpt start/end metadata
- lyric/text/structure basis
- non-instrumental eligibility
- KKr dressing-room delivery path before customer use

Time duration is not a CC creation eligibility factor for LT-PIX or KKs.

Only SWSP has a 13-second floor.
