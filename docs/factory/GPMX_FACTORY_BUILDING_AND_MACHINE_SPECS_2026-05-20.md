# GPMx Factory, Building, and HUG Chamber Manufacturing Specs
## Date: 2026-05-20

## Executive Summary

G Putnam Music, LLC is preparing a light-assembly manufacturing path for the GPM HUG Chamber System: physical keepsake product lines that connect emotional audio moments to charms, lockets, bracelets, gift cards, QR/NFC identifiers, and recipient-facing K-KUT / HUG delivery pages.

This is not heavy manufacturing.

The first stage is clean, local, trainable light assembly: assembly, packaging, QR/NFC binding, audio-link verification, gift preparation, quality control, shipping, customer support, and proof-record capture.

The public-facing product can be simple: a HUG Charm, HUG Locket, HUG Bracelet, or HUG Card.

The backend invention remains deeper: the physical chamber is bound to an emotional audio object, unique identifier, GPM-controlled delivery, metadata, personalization, recipient identity, and collectible meaning.

Core doctrine:

> The shell may vary. The chamber system is the invention.

## Three-Shop Manufacturing Model

### Factory 1 — HUG Charm Shop

Primary product:

- HUG Charm + HUG Card

Best use cases:

- wedding party thank-you gifts
- Mother's Day
- Father's Day
- friendship gifts
- teacher / coach gifts
- graduation gifts
- memorial tokens
- artist / song collectibles
- seasonal charm drops
- grandparent charms
- pet-memory charms
- collector numbered charms

Why this factory starts first:

- lowest unit complexity
- fastest assembly
- easiest shipping
- simplest packaging
- strong seasonal repeat-purchase potential
- good for holiday, wedding, memorial, and artist/song-series campaigns

Initial work areas:

- charm assembly table
- QR/NFC binding station
- printed HUG card station
- packaging station
- photo / proof-record station
- shipping / fulfillment station
- customer-support / admin station

## Facility Requirements

### Pilot Shop

Each pilot shop can begin in approximately:

- 1,000–2,500 square feet
- 2–6 workers
- clean, dry, secure workspace
- reliable internet
- standard electrical service
- assembly tables
- shelving
- shipping area
- small admin / customer-support station

### Growth Shop

Each growth shop may expand into:

- 5,000–10,000 square feet
- 10–25 workers
- expanded inventory capacity
- dedicated fulfillment lanes
- more formal quality control
- batch tracking
- local print / packaging partner support

### Combined First Facility

For a combined K-KUT / 4PE / HUG proof facility, target:

- minimum workable: 3,000–5,000 square feet
- target first facility: 5,000–15,000 square feet
- ideal serious first facility: 8,000–12,000 square feet
- growth target: 15,000–25,000+ square feet

## Seven-Machine / Equipment Path

The manufacturing plan does not require heavy equipment first. The first proof path can use small-shop, light-assembly, maker-scale equipment.

### 1. Laser Engraver / Cutter

Purpose:

- engrave charms
- engrave cards or plates
- mark serial / II identifiers
- prototype physical shells
- prepare gift / keepsake surfaces

### 2. CNC Router / Desktop CNC

Purpose:

- prototype chambers
- cut recesses
- make inserts
- shape enclosure parts
- support repeatable proof units

### 3. 3D Printer / Resin Printer

Purpose:

- rapid HUG Chamber prototypes
- charm bodies
- locket/chamber fit tests
- bracelet component tests
- internal bracket or insert forms

### 4. UV Printer / Direct-to-Object Printer

Purpose:

- print names
- print logos
- print QR/NFC visual marks
- print artwork
- print proof-unit surfaces
- personalize keepsake parts

### 5. Audio / Electronics Assembly Station

Purpose:

- test audio-link flow
- test NFC / QR identifiers
- support speaker/button/module experiments if needed
- soldering / wiring only if required
- validate physical-to-digital delivery behavior

### 6. Heat Press / Packaging / Label-Finishing Station

Purpose:

- branded packaging
- insert cards
- gift cards
- fulfillment labels
- small merch/proof pieces
- wedding / birthday / anniversary packaging

### 7. QA / Imaging / Catalog Capture Station

Purpose:

- photograph every unit
- scan / verify every code
- bind product to backend proof record
- verify audio destination
- document lineage
- support customer service and audit trail

## Backend Linkage

Every physical HUG object should connect to backend proof.

The object may carry:

- QR code
- NFC tag
- printed identifier
- card number
- batch number
- recipient record
- KUT / HUG page URL
- source PIX title
- delivery record

The backend must preserve:

- original audio source
- PIX title
- PIX-PCK linkage
- Copy-Capture / CC lineage where applicable
- II identity object
- KUT / HUG selection
- play / delivery record
- customer purchase record
- private/public status

## CC / Copy-Capture Doctrine Applied to Factory Path

CC is backend infrastructure.

CC makes, creates, and copy-captures scripted song moments, sections, parts, and pieces.

Every CC must carry:

- original MP3 SSOT URL
- exact source locator where applicable
- title
- section / part / piece identity
- metadata
- backend II linkage
- PIX-PCK linkage
- play accumulation path per PIX title

CC is not the public product.

The public product is one of:

- KK / K-KUT
- KK-Combo
- HUG
- TUG
- HUG Charm
- HUG Locket
- HUG Bracelet
- HUG Card

SWSPs may act like KUTs when governed.

INSTRO paths must be carved as first-class paths as the catalog is processed.

## Public / Private Rule

Frontend must not expose:

- PIX-PCK internals
- raw IIs
- backend CC machinery
- rights / audit metadata
- unapproved section maps
- unapproved KK candidates
- unapproved CC records

Customers may receive or purchase:

- one KK
- one approved KK-Combo
- one governed HUG/TUG
- one approved physical HUG object tied to the governed delivery path

Customers may not:

- rearrange song sections
- build custom edits
- stitch non-contiguous KKs
- access PIX-PCK internals
- access CC backend records by default
