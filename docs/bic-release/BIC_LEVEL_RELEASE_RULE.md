# BIC-Level Release Rule

## Locked Rule

BIC-level release = production audit pass, not local build pass.

## Why This Rule Exists

During the K-KUT Romance HUG release, local build passed before production was fully correct.

The release only became truly BIC after production confirmed:

- production route 200
- logo/branding asset 200
- required Romance Levels schema present
- Physical Spark buyer alias present
- forbidden internal terms absent
- all audio files served 200 audio/mpeg
- Stripe links resolved
- navigation links resolved
- delivery law passed
- production audit returned PASS

## Locked Release Authority

Do not judge by browser impression alone.
Do not judge by local build alone.
Do not judge by deployment success alone.

The release authority is production BIC audit PASS.
