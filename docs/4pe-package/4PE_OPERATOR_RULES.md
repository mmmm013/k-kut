# 4PE Operator Rules

## Operator Role

The operator controls the system.

The operator approves:

- Product definitions
- User paths
- Metadata mappings
- Public copy
- Audio inventory
- Checkout status
- Delivery readiness
- Holds / pauses
- Launch timing

## No Uncontrolled Changes

Do not change live user flow without approval.

Do not expose internal logic.

Do not add public claims without verification.

Do not promise SMS until approved.

Do not publish charity/support activity without stakeholder approval.

## User First

If a user can be confused, improve the path.

If a user can hit a dead end, add recovery.

If a user can choose a wrong-fit item, refine metadata.

If a user can hear overlapping audio, fix playback.

If a user can buy, verify checkout.

## Hold Rule

When activity is placed on hold:

- Stop outreach.
- Stop promotion.
- Stop donation collection.
- Stop public copy.
- Stop ledger updates.
- Do not resume without explicit approval.
