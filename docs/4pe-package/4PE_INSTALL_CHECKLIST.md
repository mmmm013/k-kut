# 4PE Install Checklist

## Pre-Install

- Define product use case.
- Define user path.
- Define alternate paths.
- Define metadata schema.
- Define inventory.
- Define checkout.
- Define delivery.
- Define support.
- Define audit.

## Environment

- Website host ready.
- Database ready if needed.
- Storage ready.
- Payment provider ready.
- Email ready.
- SMS ready only after compliance approval.
- Domain ready.
- Privacy page live.
- Terms page live.

## Content

- Product copy approved.
- User guide copy approved.
- BOT / guide script approved.
- Demo path approved.
- Audio files verified.
- Public links verified.
- No internal labels exposed.

## QA

- Desktop path tested.
- Mobile path tested.
- Checkout tested.
- Audio tested.
- Back path tested.
- Help path tested.
- Another-set path tested.
- Demo path tested.
- Delivery path tested.

## Launch Rule

Do not launch until buyer path and delivery path are verified.
