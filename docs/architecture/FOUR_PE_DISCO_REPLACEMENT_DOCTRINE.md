# 4PE / DISCO Replacement Doctrine

## Position

DISCO is current paid infrastructure/reference tooling.

4PE is the intended owned architecture and eventual replacement system.

DISCO may be used temporarily for:
- audio hosting reference
- playback verification
- share links
- embed links
- lyric/metadata reference
- catalog comparison
- best-practice study

DISCO is not the long-term architecture.

## Goal

4PE should eventually perform the useful catalog, playback, sharing, embed, metadata, lyric, and access functions DISCO performs, while adding GPMx-specific governance that DISCO does not provide.

## DISCO-Like Functions To Replace

4PE should support:

1. Audio upload
2. Audio playback
3. Track metadata
4. Lyric/notes storage
5. Playlist/package grouping
6. Share links
7. Embeds
8. Controlled downloads
9. Artwork
10. Private/public access states
11. Admin catalog management

## GPMx / 4PE Functions Beyond DISCO

4PE must also support:

1. PIX-PCK backend packages
2. CC exact Copy-Capture mechanism
3. II production/anchoring
4. KK governance
5. KK-Combo contiguous-only governance
6. HUG/TUG emotional delivery
7. MC-BOT guided selection
8. one governed selection per purchase
9. no user rearrangement
10. source lineage and rights metadata
11. ASCAP-aligned reporting/credit support
12. Admin promotion gates

## Architecture vs Infrastructure

DISCO is infrastructure/reference.

4PE is architecture plus eventual owned infrastructure.

Supabase may currently host files and records for 4PE, but Supabase is also infrastructure.

The architecture remains:
PIX → PIX-PCK → CC → II → governed kut/product state

## Migration Rule

Do not cancel DISCO until 4PE can replace the required operational functions for active GPMx work.

Replacement readiness requires:

- all active PIX accessible in owned storage
- playback works
- share links work
- embeds or share pages work
- lyrics/metadata stored
- Admin can manage assets
- PIX-PCK records exist
- KK/KK-Combo workflows function
- download permissions are controlled
- frontend user experience is clean

## Business Rationale

Reducing reliance on a paid third-party catalog tool can save monthly cost and increase product control.

But the larger value is not the subscription savings.

The larger value is that 4PE can do what DISCO cannot:
govern exact source lineage, CC capture, II production, K-KUT creation, rights-aware delivery, and emotional product flow.
