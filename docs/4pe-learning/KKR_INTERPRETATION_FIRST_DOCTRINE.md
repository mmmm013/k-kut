# KKr Interpretation-First Doctrine

KKr should not ask first: “Is this Sympathy?”

KKr should ask first:

What human emotional interpretations does this KK safely support, from multiple POVs, and which buyer lanes may use them?

## Locked Flow

Readings / reviews / metagrabs
→ preserved per PIX
→ preserved per KK
→ interpretation variants
→ themes
→ positive / negative / neutral connotations
→ Top 100 Shared Emotions
→ user scenarios
→ suitable KKs
→ category pages / More lists / More from this track

## Core Laws

KKs per search are not number-limited.
KKs are suitability-limited.

LT-PIX-IIs derive from KKs.
Categories derive from interpreted suitability.
Buyer pages derive only from approved lane registries.

No title-only search.
No one-term search.
No category-first publishing.

## UX Laws

First page shows strongest suitable KKs.
More for this feeling expands across the catalog.
More from this track expands within the same PIX/source.
After two More pages, guide the user to refine instead of dumping weaker options.
