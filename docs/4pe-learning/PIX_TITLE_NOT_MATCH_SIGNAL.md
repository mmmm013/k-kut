# PIX Title Is Not A Match Signal

## Locked Rule

PIX titles must not decide emotional match, buyer intent match, theme match, or KK usefulness.

PIX titles may be used only for:

- approved source authority
- backend provenance
- source lookup
- rights / owner traceability
- labeling
- QA traceability

## Correct Model

Source identity finds the allowed source material.

KK inventory is built from source identity, source audio URL, source track id, BEST/source linkage, KK id, and queue rows.

KK matching is later performed at KK level by:

- audio content
- lyric / phrase / line-pair content
- mood
- tempo / energy
- vocal tone
- instrumentation
- LineFeel tags
- use-case tags
- human QA

## Delivery Law

Raw KK proof is not customer audio.

AUDIO CAN NEVER LEAVE AN II.

Customer delivery audio must be a finished II / DP object with padding and Twinkle already baked in.
