# Browse + Return Location Rule

## Locked Rule

Stable HOME / landing stays above seasonal and holiday pages.

Holiday pages rotate underneath the stable entry system.

Buyer should always know:

- where they are
- what feeling layer they are viewing
- how to go back
- how to see More
- how to start over

## Route Shape

Stable entry:
- /personal
- /holiday

Holiday route:
- /holiday/fathers-day

Under-layer routes:
- /holiday/fathers-day?layer=cowboy
- /holiday/fathers-day?intent=missing-dad
- /holiday/fathers-day?intent=thanks-dad
- /holiday/fathers-day?intent=repair

## More Rule

More means deeper qualified options.

More does not mean raw inventory.

More may be subtler or narrower than Featured.

More may include under-layers such as Cowboy / Western Dad, Hardworking Dad, Funny Dad, Quiet Dad, Bonus Dad / Stepdad.

## Return Rule

Every deeper browse page needs clear return controls:

Back to Father’s Day
Back to Holiday HUGs
More like this
Start over
