# No Mystery KK Structure Standard

## Locked Rule

A K-KUT / KK is one natural song section.

A KK-Kombo is two or more KKs joined together.

All KKs used in a KK-Kombo must be contiguous.

Non-contiguous KK-Kombos are forbidden.

## No Mystery Lone-Section KKs

No Mystery has seven lone-section KKs:

1. Intro + V1
2. Ch1
3. V2
4. Ch2
5. Br
6. Ch3 / Final Chorus
7. Outro

V2 must not be omitted.

Intro + V1 counts as one KK because that is the natural song unit.

Outro stays separate from Final Chorus because Final Chorus usually has broader emotional and sales range.

## No Mystery Approved Contiguous KK-Kombos

Approved pre-made contiguous KK-Kombos:

- Intro + V1 + Ch1
- V2 + Ch2
- Br + Ch3 + Outro
- Br + Ch3
- Ch3 + Outro

These are combos because they contain more than one KK.

They are valid only because every included KK is contiguous.

## Matching Rule

PIX title is not a buyer-match signal.

The title No Mystery is used for:

- provenance
- source lookup
- backend tracking
- labeling
- rights tracking
- QA traceability

Buyer fit must come from KK-level content, feel, audio, lyrics/line, and QA.

## Delivery Rule

Raw KK proof is not customer audio.

AUDIO CAN NEVER LEAVE AN II.

Each public delivery must be a finished II / DP object with padding and Twinkle baked in.
