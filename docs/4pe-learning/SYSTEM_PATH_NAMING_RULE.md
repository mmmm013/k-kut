# System Path Naming Rule

## Locked Rule

Do not use customer-facing names, holidays, people names, song titles, PIX titles, artist names, or promo titles as system component names.

Customer-facing labels may appear in UI copy when appropriate.

System paths must use neutral operational naming.

## Wrong

- public/mothers-day/... for internal review audio
- public/fathers-day/... for internal proof packs
- public/<song-title>/... as system routing
- path names that expose buyer campaigns as backend architecture

## Right

- public/_review/...
- public/_proof/...
- public/_ops/...
- public/ii-delivery/...
- data/system/...
- manifests/kkr/...
- reports/...

## Audio Rule

Review/proof audio is not customer delivery audio.

Customer delivery audio must be finished II / DP audio with padding and Twinkle baked in.

AUDIO CAN NEVER LEAVE AN II.
