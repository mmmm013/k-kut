# Father’s Day KK Authority Process

## Locked Rule

Father’s Day KK extraction must be title-authority first.

Do not use broad emotional matching as the source of truth.

Do not import romance, apology, repair, KUPID, reusable-II, or unrelated registry inventory into Father’s Day just because the words feel compatible.

## Approved Father’s Day Source Authority

Current approved source-title authority set:

- i'M NO MYSTERY / I'm No Mystery / No Mystery
- Life’s a Test / Life's a Test

## Required Process

1. Load approved Father’s Day source-title authority.
2. Search only for those source titles and approved variants.
3. Expand each source into individual KK rows.
4. Preserve KK id, title, timing, source evidence, and file evidence.
5. Mark raw KK rows as candidate/proof only.
6. Do not treat raw KK as public audio.
7. Do not materialize until ADMIN/GPM approval.
8. Do not include excluded titles unless ADMIN explicitly adds them to the Father’s Day authority file.
9. Produce a contamination audit.
10. Produce a collapse audit.

## Collapse Rule

A source such as No Mystery must not appear as one mega candidate if individual KKs exist.

The extractor must show individual KK rows.

## Delivery Law

KK candidate = proof / selection layer.

II delivery = finished customer-ready file with padding and Twinkle baked in.

AUDIO CAN NEVER LEAVE AN II.
