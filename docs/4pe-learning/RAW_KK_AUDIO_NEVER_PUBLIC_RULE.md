# Raw KK Audio Never Public Rule

## Locked Rule

Raw KK audio is never public customer audio.

KKs and KK-Kombos may be searched, suggested, selected, compared, and assembled internally.

They become customer-facing only after materialization into finished II / DP audio.

AUDIO CAN NEVER LEAVE AN II.

## Meaning

PIX:
- source inventory

KK:
- selected/cut music moment
- candidate layer
- not public playback by default

KK-Kombo:
- combined candidate idea
- may be guided by MC-BOT on request
- not default storefront inventory
- not public playback until materialized

II:
- finished customer-ready audio object
- contains front padding, selected KK or approved assembled audio, back padding, and Twinkle baked into the file

CI:
- Cost Item
- sellable financial item tied to finished II or II-based offer

DP:
- Delivery Package
- governed fulfillment package finalized by payment and QA/QC

## Public Playback Rule

Public buyer pages may only play finished II delivery audio.

Public buyer pages must not play:

- raw PIX audio
- raw KK audio
- raw KK-Kombo audio
- Supabase source-track URLs
- unfinished candidate audio
- runtime-assembled padding
- runtime-appended Twinkle

## MC-BOT Rule

MC-BOT may say:

- “I can look for a combined option.”
- “I can help build a more layered HUG.”
- “I can search deeper.”
- “I can compare more candidates.”
- “This may become a custom Delivery Package.”

MC-BOT must not expose raw KK audio, raw PIX audio, internal IDs, or unfinished candidate audio.

## Materialization Rule

A KK or KK-Kombo becomes customer-facing only after:

1. ADMIN / GPM approval
2. finished audio creation
3. front padding baked in
4. back padding baked in
5. Twinkle / signature end baked in
6. saved under /ii-delivery/ or governed DP delivery path
7. audit pass
8. CI / DP connection

## K-KUT Current Public Rule

For now, k-kut.com public storefront should keep the default buyer path simple:

- Featured
- More
- More page 2
- finished II audio
- Stripe / CI
- DP fulfillment

KK-Kombos remain guided/custom through MC-BOT request behavior, not default storefront clutter.
