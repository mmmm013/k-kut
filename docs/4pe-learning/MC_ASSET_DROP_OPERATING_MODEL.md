# MC Asset Drop Operating Model

## Locked Rule

MC adds assets to a simple shared folder / upload inbox.

Greg/GPM reviews and imports.

Vercel is not the easy asset explorer.

## Roles

MC = asset contributor.

Shared folder = upload inbox.

GPM = reviewer/importer.

KKr = classification, matching, candidate routing, and reuse governance.

BIC = public release gate.

Vercel = deployment system, not asset storage or casual upload workspace.

## Why

MC should be able to contribute like using a normal computer folder.

MC should not need to manage:

- Vercel deployments
- environment variables
- domains
- production releases
- Git pushes
- public buyer UI

## README Text

Upload files here like a normal folder.

Please do not delete or rename other people’s files.

Use clear names when possible.

Good examples:

MCBOT_fathers-day_more-like-this_take-01.m4a

MCBOT_cowboy-dad_phrase-01.m4a

KLEIGH_stream_photo_01.jpg

song-title_reference_mix.wav

After uploading, message Greg:

1. what you uploaded
2. what it is for
3. final / rough / idea-only

Uploading here does not automatically publish anything.

Greg/GPM reviews and imports approved assets into the correct system.

## Release Law

An uploaded asset is not public.

An uploaded asset is not approved.

An uploaded asset is not customer-ready.

Public release requires:

- GPM review
- KKr classification
- source/rights confirmation where needed
- delivery materialization when needed
- padding + Twinkle for customer audio
- route/config update
- production BIC audit PASS
