# MIN-8 Theme Depth Standard

## Locked Rule

Every public buyer theme must provide a minimum of 8 customer-ready options.

The emergency 3-option patch is only a safety floor.

## Standards

Safety floor:
- 3 customer-ready II options
- allowed only as emergency coverage

Buyer choice floor:
- minimum 8 customer-ready options per theme
- each option must be buyer-facing
- each option must have playable II delivery audio
- each option must use /ii-delivery/
- each option must include bookend-twinkle
- each option must have an approved Stripe path

Strong theme:
- 12 to 20 customer-ready options

Mature theme:
- Featured
- More
- More like this
- MC-BOT narrowing
- weekly exposure rotation

## Do Not Fake Depth

Eight cards reusing the same 3 audio files is not real depth.

Temporary reuse is allowed only when marked as safety coverage.

Real MIN-8 means at least 8 distinct customer-ready II delivery audio files for the theme or an explicit ADMIN exception.
