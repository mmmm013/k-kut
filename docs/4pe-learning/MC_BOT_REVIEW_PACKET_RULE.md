# MC-BOT Review Packet Rule

## Locked Rule

Email MC only when there is enough coherent MC-BOT script / phrase material to warrant review.

Do not send scattered fragments.

Collect, classify, and send a clean packet.

## Threshold Before Email

Minimum standard before creating the MC email draft:

- 20 useful phrases
- 3 theme branches
- purpose note
- buyer-facing phrase set
- tone direction
- clear ask
- clear non-ask

## Tone Law

Natural Michael Clay pace.

Human, grounded, plainspoken.

No generic AI/browser voice tone.

Guide the buyer without sounding salesy.

Keep phrases short enough to speak naturally.

Never expose internal labels, forbidden inventory, or unreleased candidates.

## Current Use

Father’s Day and Theme Feed are now collecting MC-BOT phrases.

When the packet is strong enough, create a Gmail draft to MC for review.

Do not send without user approval.
