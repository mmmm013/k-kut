# KUT Candidate Rolling Queue Rule v1

There is no fixed “approved” pile.

The lane is:

`Next-in-line KUT Candidate → In processing → Processed candidate review → Release Gate → Outlet / Release`

Or:

`Next-in-line KUT Candidate → In processing → Processed candidate review → Recut / Hold`

When a candidate moves into processing, it leaves the Next-in-line lane. The next best eligible candidate may then move forward.

Next-in-line is not release-ready. It is only controlled processing attention.
